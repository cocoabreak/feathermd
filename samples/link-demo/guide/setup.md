# セットアップガイド

FeatherMDで`samples/link-demo`フォルダーを開き、`index.md`を選択します。

## 基本操作

1. 左サイドバーからリンク一覧を開きます。
2. 出力リンクと入力リンクを切り替えます。
3. グラフを開き、現在文書の周辺だけが表示されることを確認します。
4. 本文内のリンクへポインターを置き、プレビューを確認します。
