# FeatherMD v0.2.5 release QA

Date: 2026-09-23

## Scope

Styled GitHub Alerts and Obsidian Callouts, performance reporting and CI size
limits, security-scan fixes, compatible dependency updates, Shiki 4.4.3, and
the time upper-bound removal evaluated in [#48](rust-dependencies-48.md).

## Functional and dependency checks

The source entering version preparation passed:

- [x] Frontend formatting, ESLint, and svelte-check (zero errors/warnings)
- [x] All 402 frontend tests and 106 performance-tool tests
- [x] Rust formatting, Clippy with warnings denied, and 153 library tests
- [x] Production frontend build and exclusion of the E2E hook
- [x] Windows release build
- [x] Seven isolated Windows WebView2 smoke scenarios
- [x] Additional Callout rendering, initial open/closed states, and click-to-expand
- [x] npm audit (three low findings, none moderate or higher)
- [x] Cargo audit (zero vulnerabilities, seven existing upstream warnings)
- [x] Independent design and security reviews of #48 (no findings)

The seven smoke scenarios cover Markdown, valid and invalid Mermaid, ZIP,
the 5 MiB safe-mode boundary, update notification, and reload restoration of
tabs, search, and scroll. The Callout sample was also visually inspected.

## Release candidate gates

- [ ] Confirm version consistency across all five package/configuration files
- [ ] Build Windows MSI, NSIS, and portable ZIP distributions
- [ ] Pass frontend size budgets on a clean candidate commit
- [ ] Complete isolated release timing and memory suites and review their results
- [ ] Complete release preparation review and all PR checks
- [ ] Merge the release candidate and create the v0.2.5 tag
- [ ] Confirm Windows, macOS, and Linux release jobs succeed
- [ ] Verify published asset candidates against SHA256SUMS.txt
- [ ] Publish the Draft Release

## Known limitations

- Windows binaries are unsigned. macOS binaries are not notarized.
- Linux and macOS builds are release gates; interactive runtime QA is performed
  on Windows only.
- The three low npm findings are in SvelteKit development tooling for this
  statically built application. No forced breaking downgrade is applied.
- Cargo's seven informational warnings come from upstream GTK3/glib and
  urlpattern/UNIC dependencies; see the #48 evaluation for paths and constraints.
- Existing Vite chunk/import optimization notices and MSVC DLL import-library
  output notices are non-blocking. Clippy itself passes with warnings denied.
