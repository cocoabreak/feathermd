limits, security-scan fixes, compatible dependency updates, Shiki 4.4.3, and
the time upper-bound removal evaluated in [#48](rust-dependencies-48.md).

Comparison status is **partial**, not a complete comparable baseline result:
the August baseline lacks the ten newly added cold/warm startup phase metrics.
All current metrics are measured; unavailable comparisons remain explicitly
marked as missing baseline values. Common startup totals increased 2.50%/4.30%;
render medians decreased 0.20% to 5.48%; memory changes range from -3.13% to
+2.23%. Rust, Node, WebView2, and Tauri CLI versions have changed since that
baseline, so these differences cannot be attributed solely to application code.
No large regression was observed in the common metrics. The historical Shiki
raw-size increase is covered by the separately reviewed #49/#51 size-budget
adjustment, which the candidate passes.

The first timing attempt stopped before launch because the packaged execution
host redirected AppData outside the expected direct parent. Its failed results
were retained locally. The complete suites were rerun from an ordinary Windows
process, without weakening ownership/path checks or changing the application.
The successful suites also verified normal-profile store isolation.

Independent release-record review found no P0-P3 issues. It recalculated all
timing summaries, process memory totals, and comparison deltas, reproduced the
comparison JSON, and verified the public-data checks.

## Known limitations

- Windows binaries are unsigned. macOS binaries are not notarized.
- Linux and macOS builds are release gates; interactive runtime QA is performed
  on Windows only.
- The three low npm findings are in SvelteKit development tooling for this
  statically built application. No forced breaking downgrade is applied.
- Cargo's seven informational warnings come from upstream GTK3/glib and
  urlpattern/UNIC dependencies; see the #48 evaluation for paths and constraints.
- Existing Vite chunk/import optimization notices and MSVC DLL import-library
  output notices are non-blocking. Clippy itself passes with warnings denied.
