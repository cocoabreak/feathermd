# FeatherMD v0.2.4 release QA

Date: 2026-08-02

## Scope

This document tracks the final verification of FeatherMD v0.2.4. The release adds document-reference copying, expanded link-problem detection, user-selected local fonts, and reproducible Windows release performance measurement.

Platform-specific GitHub Actions builds and inspection of their generated artifacts remain release gates before publishing the release.

## Dependency review

- `npm outdated` found compatible patch and minor updates plus major updates for several development and rendering packages. They are not required for a known moderate-or-higher vulnerability and are deferred to a dedicated dependency update to keep the release candidate scope stable.
- `npm audit --audit-level=moderate` reported three low-severity findings inherited through SvelteKit's development dependency graph. FeatherMD uses the static adapter and does not ship a SvelteKit server; no moderate-or-higher finding remains.
- `cargo audit` reported no vulnerabilities and uses no ignored advisories. The previous `event-listener 5.4.1` soundness warning was removed by updating the compatible transitive dependency to `5.4.2`.
- Seventeen non-blocking RustSec warnings remain in upstream Tauri dependencies: GTK3 bindings used by the Linux WebView stack, `urlpattern`'s `unic-*` dependencies, and related unmaintained or soundness notices. These are transitive dependencies without compatible replacements in the current Tauri line and remain covered by CI's Cargo audit gate.

## Reviewed release scope

- Copying document and heading references as Wiki links, Markdown links, and Source-relative paths
- Missing document, image, and heading-anchor reporting in the link inspector
- Local body and code fonts, managed copies, restart restoration, custom CSS ordering, and printing
- Release CSP and raw binary IPC handling for local fonts
- Windows frontend size, startup, rendering, and process-tree memory measurement
- Isolation of performance builds, AppData, WebView2 profiles, fixtures, and production bundles

## Known release notes

- Windows binaries are not code-signed and may trigger Microsoft Defender SmartScreen. Users should obtain binaries only from the official Releases page.
- The three low-severity npm advisories are development-only and cannot currently be removed without an inappropriate forced breaking downgrade of SvelteKit.
- Production frontend builds may report existing large-chunk and dynamic-import optimization warnings. These warnings are monitored by the new report-only performance metrics and are non-blocking for v0.2.4.
- Linux and macOS artifacts remain best-effort. macOS builds are not notarized.
