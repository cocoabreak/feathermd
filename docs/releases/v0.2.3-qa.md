# FeatherMD v0.2.3 release QA

Date: 2026-07-27

## Scope

This document tracks the final verification of FeatherMD v0.2.3. This release adds the link inspector, local link graph, and bounded link previews; fixes multiline Mermaid labels; updates development dependencies; and adds application visuals to the English and Japanese READMEs.

Platform-specific GitHub Actions builds and inspection of their generated artifacts remain release gates before publishing the release.

Results from the release candidate:

- `svelte-check` completed with 0 errors and 0 warnings; ESLint and Prettier completed successfully.
- Vitest completed 306 tests in 71 files with no failures.
- The production frontend build completed successfully and contains no E2E-only hook.
- Rust completed 131 tests with no failures; rustfmt and Clippy completed successfully.
- The Windows WebView2 smoke suite completed all 7 scenarios, including multiline Mermaid rendering, ZIP viewing, safe mode, update notification, and session restoration.
- `npm audit --audit-level=moderate` reported three low-severity transitive findings in SvelteKit's development dependency graph; no moderate-or-higher finding remains.
- Local `cargo audit` was not run because it requires separate approval to send dependency metadata to an external advisory service. The GitHub Actions security-audit job remains a release gate.

## Reviewed behavior

- Link inspection for incoming, outgoing, Wiki, Markdown, and broken links
- Local link graph navigation and broken-link visualization
- Document and graph hover previews, keyboard focus, missing targets, and preview bounds
- Shared secure link resolution with absolute paths excluded from passive previews
- Multiline Mermaid node-label rendering with sanitization preserved
- English and Japanese README screenshots and animated preview demonstration

## Known release notes

- Windows binaries are not code-signed and may trigger Microsoft Defender SmartScreen. Users should obtain binaries only from the official Releases page.
- The low-severity npm advisories are inherited through a development-only SvelteKit dependency path. FeatherMD uses the static adapter and does not ship a SvelteKit server; moderate-or-higher findings remain release-blocking.
- Production frontend builds report existing large-chunk and dynamic-import optimization warnings. These warnings are non-blocking for v0.2.3.
- Linux and macOS artifacts remain best-effort. macOS builds are not notarized.
