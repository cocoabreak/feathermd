# Hiranoa 0.3.1 QA

## Scope

Issue #56: resolve Markdown directory links to `index.md` in local folders and ZIP archives. Preserve anchors and align navigation, preview, link inspection, backlinks, and the graph. No README fallback or dependency updates.

## Local validation

- Frontend Prettier, ESLint, and svelte-check passed (0 errors / warnings). Existing ignored `e2e/artifacts` scripts were excluded from formatting/linting; no artifact files were changed.
- Vitest: 81 files / 415 tests passed.
- Rust format, Clippy with warnings denied, and 155 tests passed.
- Native and ZIP tests cover directory aliases, Source root and parent links, percent-encoded spaces, dotted names, missing index/README-only directories, ordinary files, preview targets, incoming links, and heading validation.
- Relative navigation decodes percent encoding exactly once. Native/ZIP regression cases cover spaces, Japanese names, literal percent sequences, and encoded Source escapes. Preview candidates preserve a trailing directory slash for missing dotted names.
- Native directory and index-file symlink escapes to another trusted root were rejected. The symlink test executed without its Windows privilege fallback.
- WebView2 smoke passed: Native and ZIP directory previews, anchored clicks, same-document links, bare directory links, direct index links, tab reuse, plus the existing Markdown/Mermaid/ZIP/large-file/update/session scenarios.
- Performance tooling: 106 tests passed. Frontend size budget and production build passed; production output contains no E2E hooks.
- `npm audit --audit-level=high` passed with the same three low-severity cookie/SvelteKit findings as 0.3.0.
- `cargo audit` passed with the same seven allowed advisory warnings as 0.3.0.
- Package, lockfile, Tauri, and Cargo versions are 0.3.1.
- Final Windows release build generated MSI and NSIS installers successfully. Installers were built, not installed over the user's application.

## Review and publication

Independent design/diff review found the relative percent-decoding mismatch described above; it was fixed and covered by unit and Native/ZIP click tests. Final review results and publication are recorded in the feature PR and Issue #56. Publication requires successful PR CI, the tagged multiplatform build, and checksum verification.

Independent design/diff and security re-reviews completed with no remaining P0–P3 findings.

## Limits

Windows is the runtime verification platform. macOS/Linux packaging is checked by the release workflow; runtime and installation on those platforms are not covered. Full startup/memory performance benchmarking is not repeated for this link-resolution feature; the existing fixture tests and frontend size budget are checked.
