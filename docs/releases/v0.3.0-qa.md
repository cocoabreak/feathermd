# Hiranoa 0.3.0 QA

## Scope

Rename FeatherMD to Hiranoa with a new application identifier and an open-book icon. This is a fresh installation, without automatic import or deletion of FeatherMD data. Existing releases and fixed performance fixtures retain their historical names.

## Local validation

- Frontend format, ESLint, and svelte-check: passed; no type errors or warnings.
- Vitest: 81 files / 402 tests passed.
- Performance tooling: 106 tests passed; fixed fixture hashes preserved.
- Rust format, Clippy with warnings denied, and 153 tests: passed. The Windows test/build linker emits an informational import-library message.
- `npm audit --audit-level=high`: passed; three low-severity findings in the existing cookie/SvelteKit chain remain. No forced dependency downgrade applied.
- `cargo audit`: passed with seven existing allowed advisory warnings (unmaintained crates and glib unsoundness).
- Windows release build: NSIS and MSI generated as Hiranoa 0.3.0.
- Installer inspection: MSI uses a new UpgradeCode; NSIS uses Hiranoa product/uninstall identity and `com.cocoabreak.hiranoa`.
- Production output contains no `window.__e2e` hook.
- WebView2 smoke: Markdown, valid/invalid Mermaid, ZIP, large-file safe mode, update notification, and session restoration passed.
- Isolated UI inspection: sample folder browsing, Hiranoa title, About version 0.3.0, and new icon passed. Folder setup uses the debug-only authorization hook; no native folder confirmation is automated.
- Public overview screenshot replaces the machine-specific status-bar path with a relative sample path during capture.

## Limits

- The Windows installers were built and inspected, not installed over the user's existing application.
- macOS/Linux packages and final repository/update URLs are verified by the release workflow and post-rename checks.
- The icon was produced with the built-in image generation tool from the approved Hiranoa A concept: ivory open book with a raised right page, periwinkle background, no text. The checked-in master is opaque because generated transparent variants had edge artifacts. Tauri CLI produces the platform sizes; favicon/About use the generated 128px PNG.
