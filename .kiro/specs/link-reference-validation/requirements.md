# 要求定義: リンク参照検証の拡張

## 背景・目的

リンクインスペクターはWikiリンクとMarkdown文書リンクのリンク切れを表示できるが、
ローカル画像と見出しアンカーは検証しない。文書自体が存在しても表示時に参照できない
画像や見出しを、既存のDocumentSourceと信頼境界を維持したまま「問題」一覧で確認できるようにする。

GitHub Issue: #14

## スコープ

- 現在文書が参照するローカル画像の存在・Source境界の検証
- 同一文書および同一DocumentSource内Markdown文書の見出しアンカー検証
- WikiリンクとMarkdownリンクで共通の見出しID規則を使用
- NativeSourceとZipSourceで共通の問題表示
- 既存の文書リンク切れを含む「問題」一覧への統合

## 対象外

- 外部HTTPS URLの到達確認、外部画像の取得
- 画像データの完全なデコード検査
- 文書や参照の自動修正
- フォルダー全体の常時lint
- Mermaid、KaTeX、カスタムレンダラー内の参照
- 問題項目のソース行番号表示

## US-001: ローカル画像の問題を確認する

- [x] Markdown画像構文が指すローカル画像が存在しない場合、「問題」へ表示する
- [x] Sourceルート外、NativeSourceの信頼ルート外、ZipSource外への参照を「範囲外」として表示する。NativeSource内の絶対パスは既存表示経路と同じく許可する
- [x] 外部URLとdata URLはローカル画像検証の対象にしない
- [x] 同じ画像参照が複数回現れる場合は参照数へ集約する
- [x] 項目に画像種別、参照文字列、状態を表示する
- [x] ファイルを画像としてデコードできるかは検証しない

## US-002: 見出しアンカーの問題を確認する

- [x] 同一文書内の見出しアンカーが存在しない場合、「問題」へ表示する
- [x] 解決済みのWikiリンクとMarkdown文書リンクについて、指定された見出しが存在しない場合、「問題」へ表示する
- [x] percent-encodedアンカー、Unicode、重複見出し、空slug、emoji、インラインコードを本文レンダリングと同じ規則で照合する
- [x] 文書リンク自体が存在しない場合は既存のリンク切れだけを表示し、見出し欠落を重複表示しない
- [x] 読込上限、解析上限、個別読込失敗により存在を断定できない場合は「検証できない」として表示する
- [x] 項目に参照種別、対象文書、見出し名、状態を表示する

## US-003: 既存の問題一覧へ統合する

- [x] リンクインスペクターの第3区分を「問題」として表示する
- [x] 既存の文書リンク切れ、画像問題、見出し問題を同じ一覧に表示する
- [x] 問題種別と状態を視覚表示と読み上げテキストの両方で識別できる
- [x] 読込中、空、失敗、省略ありを区別する
- [x] リンクグラフは従来どおり文書リンクだけを扱い、画像・見出し問題をノード化しない

## US-004: 安全かつ制限付きに検証する

- [x] リンクタブまたはグラフを開くまで追加検証を開始しない
- [x] Source ID、generation、隠しファイル設定、gitignore設定、Wikiリンク設定をキャッシュスコープへ含める
- [x] NativeSourceの画像・文書はAllowedRootsと最終ファイルハンドルパスの既存検証を通す
- [x] ZipSourceは検証済み中央ディレクトリと既存の圧縮・展開上限を使用する
- [x] 検証文書数、1文書サイズ、総読込量、見出し数、問題数、文字列総量、応答サイズへ個別上限を設ける
- [x] watcher、Source generation変更、明示更新後は次回表示時に再検証する
- [x] 上限到達や個別失敗でリンク切れと断定せず、部分結果と省略状態を返す
- [x] 生Markdown、HTML、絶対ネイティブパスをWebViewへ返さない

## 非機能要求

- 新しいRust依存、外部通信、永続化ファイルを追加しない
- 見出しID生成は既存の`heading-anchor.ts`を唯一の正規化実装として再利用する
- 既存のリンク索引、バックリンク、リンクプレビュー、リンクグラフ、明示クリック時の遷移に回帰を起こさない
- 問題一覧へ描画する項目は最大500件とする

## 設計上の決定

- [x] 画像は存在とSource境界だけを検証し、デコード可否は対象外とする
- [x] 見出し構造の抽出はRust、見出しIDの最終生成と照合は既存TypeScript実装を使用する
- [x] 「欠落」「範囲外」「検証できない」を区別する
- [x] 画像・見出し問題はリンクグラフへ含めない
- [x] 検証はリンクインスペクターを開いた時点で遅延実行する
