# 要求定義: ローカルフォント (local-fonts)

## 背景・動機

FeatherMDはカスタムCSSに対応しているが、安全性を維持するため `url()` と `@import` を禁止している。そのため、ユーザーが所有するローカルフォントをMarkdown本文へ適用する安全な経路がない。

任意の外部リソース参照を解禁せず、ネイティブファイル選択で明示されたフォントだけを用途限定で取り込み、アプリUIへ影響させずMarkdown本文へ適用できるようにする。

## スコープ

- **対象**: Markdown本文用フォント1件、コード・等幅表示用フォント1件、選択・置換・解除、有効/無効、永続化、即時反映、印刷/PDF
- **対応形式**: WOFF2、TrueType（TTF）、OpenType（OTF）
- **対象外**: WOFF、TTC/OTC、Webフォント、任意URL、システムフォント一覧、見出し専用フォント、複数ウェイト管理、フォント編集・変換、元ファイルの自動監視、単一HTML出力へのフォント埋め込み、アプリUI全体のフォント変更

## ユーザーストーリー

### US-001: 本文用・コード用フォントの管理

As a ユーザー
I want to 所有するローカルフォントを本文用またはコード用として選択したい
So that Markdownを好みの書体で読みたい

**受け入れ条件**

- [x] 設定画面から本文用とコード用を独立して選択、置換、解除できる
- [x] 選択はRustネイティブファイルダイアログからのみ行う
- [x] 選択時に拡張子、実ファイルシグネチャ、ファイルサイズをRust側で検証する
- [x] 1ファイルは32 MiB以下、2スロットの合計は64 MiB以下とする
- [x] 検証済みフォントをidentifier固有のアプリ管理領域へコピーし、元ファイルの移動・削除後も利用できる
- [x] 設定や表示用メタデータへ元ファイルの絶対パスを保存せず、元のファイル名、形式、サイズだけを表示する
- [x] 解除時は対応する管理コピーとメタデータを削除する

### US-002: Markdown本文への適用

As a ユーザー
I want to 選択したフォントをすぐに有効化・無効化したい
So that 表示を比較しながら安全に調整したい

**受け入れ条件**

- [x] ローカルフォント全体の有効/無効を設定画面で切り替えられ、再起動後も維持される
- [x] 本文用フォントは `.markdown-body` の通常本文へ、コード用フォントはその配下のコード・等幅要素へ適用する
- [x] タブ、サイドバー、目次、設定、ダイアログ、検索、ソース確認等のアプリUIには適用しない
- [x] 選択、置換、解除、有効/無効が再起動なしで即時反映される
- [x] 未設定スロット、無効時、読込失敗時は既定フォントへフォールバックする
- [x] KaTeX等が専用フォントを指定する領域は、そのプラグインの既定表示を優先する

### US-003: 既存カスタマイズ・出力との共存

As a ユーザー
I want to ローカルフォントを既存の表示設定や出力機能と併用したい
So that 現在の閲覧・共有方法を維持できる

**受け入れ条件**

- [x] コンテンツズームとローカルフォントを同時に使用できる
- [x] カスタムCSSをローカルフォント指定より後勝ちにし、明示的な `font-family` 上書きを維持する
- [x] 印刷/PDF開始前に選択済みフォントのロード完了を待ち、表示中と同じフォントを使用する
- [x] 単一HTML出力にはフォントデータやローカル参照を埋め込まず、既定フォントへフォールバック可能なHTMLを生成する

### US-004: CJKフォントの実用性

As a 日本語・CJK文書のユーザー
I want to 大きなCJKフォントでも安定して表示したい
So that 日本語本文とコードを欠落なく読みたい

**受け入れ条件**

- [x] 日本語の漢字、ひらがな、カタカナ、全角・半角記号を含むfixtureで表示を確認する
- [x] 公式配布の Noto Sans CJK JP を本文用、Noto Sans Mono CJK JP をコード用にした実アプリ確認を行う
- [x] CJKフォントはBase64文字列やJSON数値配列ではなく、Tauriのraw binary IPCからWebViewへ渡す
- [x] CJKフォント適用後もUI応答、タブ切替、ズーム、印刷/PDFが継続できる

## 安全性・非機能要求

- ネットワークURL、CSSの `url()`、`@import`、asset protocolを有効化しない
- WebViewから任意の読込元・削除先パスを指定できるコマンドを公開しない
- Rustコマンドは固定の `body` / `code` スロットだけを受け付け、管理領域外を読み書きしない
- ネイティブダイアログで選択されたパスはRust側で一度だけ開き、開いた同一ファイルハンドルから上限付きで検証・コピーして、検証後の再オープンによる差し替えを避ける
- 管理コピーのロード時にもサイズとシグネチャを再検証し、不正・破損時はfail-closedに拒否する
- 一時ファイルからの置換で更新し、失敗時に直前の正常なフォントを壊さない
- 読込・適用要求を世代管理し、遅れて完了した古いフォントで最新設定を上書きしない
- フォント読込失敗によってアプリ起動、Markdown表示、設定画面を失敗させない
- 通常版とperformance版はTauri identifier固有のAppDataにより管理コピーを分離する
- 実在するローカル絶対パス、OSユーザー名、フォントバイト列をログ、性能結果、テスト成果物へ保存しない
- Noto CJKを含む第三者フォントをリポジトリへ同梱する場合は、配布元、著作権表示、ライセンス、改変時の名称条件を確認する。初期実装ではCJKフォント本体をコミットしない
