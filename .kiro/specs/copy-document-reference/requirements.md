# 要求定義: 文書・見出し参照のコピー

GitHub Issue: #3

## 背景・目的

閲覧中の文書や見出しを別のMarkdown文書から参照するには、ファイルパス、表示名、見出しアンカーを
手作業で組み立てる必要がある。FeatherMDをビューワー専用のまま維持しつつ、現在の文書または見出しを
指す参照表現をクリップボードへコピーできるようにする。

## スコープ

- 現在文書のWikiリンク、Markdownリンク、パスのコピー
- 現在文書内の見出しを含むWikiリンク、Markdownリンク、見出し名のコピー
- 本文コンテキストメニュー、目次、コマンドパレットからの操作
- NativeSourceとZipSource
- Sourceルート基準のMarkdownリンク
- Unicodeと重複見出しを扱う共通アンカー生成
- コピー結果の通知

## 対象外

- 文書の編集や参照の自動挿入
- 貼り付け先文書を選択して相対パスを計算する機能
- OSやアプリをまたぐ独自リンクプロトコル
- frontmatterや先頭H1を文書タイトルとして推測する機能
- 外部URLとして共有可能なリンクの生成
- ZIP内文書を直接開くOSファイルパスの生成

## US-001: 文書参照をコピーする

- [x] 現在文書がある場合、本文コンテキストメニューから文書のWikiリンクをコピーできる
- [x] 現在文書がある場合、本文コンテキストメニューから文書のMarkdownリンクをコピーできる
- [x] NativeSourceでは実ファイルパス、ZipSourceではアーカイブパスとエントリを含む表示パスをコピーできる
- [x] 文書参照の表示名はMarkdown拡張子を除いたファイル名とする
- [x] コマンドパレットからも現在文書の3形式をコピーできる
- [x] 文書が開かれていない場合、参照コピーコマンドをコマンドパレットへ表示しない

## US-002: 見出し参照をコピーする

- [x] レンダー表示の見出し上でコンテキストメニューを開くと、見出し付きWikiリンク、見出し付きMarkdownリンク、見出し名をコピーできる
- [x] 目次項目のコンテキストメニューから同じ3形式をコピーできる
- [x] 見出し付き参照は、実際に本文へ付与された一意なアンカーIDを使用する
- [x] 日本語等のUnicode見出しを意味のあるアンカーとしてコピーできる
- [x] 重複見出しは2件目以降へ決定的な数値サフィックスを付けて区別する
- [x] セーフモードまたはソース表示でも、目次に存在する見出しは目次項目からコピーできる

## US-003: Sourceルート基準で参照する

- [x] WikiリンクはSource内フルパスと拡張子を使用する（例: `[[docs/guide.md]]`）
- [x] Markdownリンクは先頭`/`をSourceルートとして使用する（例: `[guide](</docs/guide.md>)`）
- [x] 見出し付き参照は各ターゲットへ`#アンカーID`を付与する
- [x] SourceルートMarkdownリンクを現在文書の階層に依存せずNativeSourceとZipSourceで開ける
- [x] Windowsドライブ絶対パスとUNCパスの既存処理をSourceルートリンクと混同しない
- [x] リンク索引とリンクプレビューもSourceルートMarkdownリンクを同じ規則で解決する

## US-004: 結果と失敗を通知する

- [x] コピー成功時に短時間のメッセージを表示する
- [x] コピー失敗時にエラーメッセージを表示し、アプリ操作を継続できる
- [x] 通知はスクリーンリーダーへ読み上げられる
- [x] ファイルパスは利用者が明示的に選んだ形式でのみコピーし、既定形式にはしない

## 非機能要求

- 参照文字列生成はDOMのHTMLや未検証属性を使用せず、現在タブのDocumentRef、DocumentSourceInfo、TOC見出しから行う
- コピー文字列をHTMLとして挿入しない
- 新しいRustコマンド、ファイル読込、外部通信、永続化を追加しない
- 既存のAllowedRoots、DocumentSource、Wikiリンク解決、リンク索引の信頼境界を維持する
- メニューの失敗やClipboard APIの拒否で文書表示を失敗させない

## 設計上の決定

- [x] Markdownリンクの基準は貼り付け先ではなくDocumentSourceルートとする
- [x] SourceルートMarkdownリンクは`/`で明示する
- [x] Wikiリンクは曖昧さを減らすためSource内フルパスと拡張子を含める
- [x] 文書タイトルはファイル名からMarkdown拡張子を除いた値とする
- [x] 見出し参照は見出し表示名ではなく一意なアンカーIDをターゲットへ使用する
- [x] コンテキストメニューと目次を見出し指定の主導線、コマンドパレットを文書指定の補助導線とする
