# 要求定義: Hiranoaへの改名

## 方針

FeatherMDをHiranoa（ヒラノア）へ改名し、0.3.0を新規インストールとして配布する。
複数のMarkdownをフォルダーやZIPから一冊の本のように読む製品として、開いた本のアイコンを採用する。

## 受け入れ条件

- [x] 表示名・配布名・開発ツールをHiranoa / hiranoaへ統一する。
- [x] npm・Cargo・Tauriとロックファイルの製品バージョンを0.3.0へ統一する。
- [x] アプリIDを`com.cocoabreak.hiranoa`、性能測定用を`com.cocoabreak.hiranoa.performance`とする。
- [x] 旧版の設定・履歴・タブ・ローカルフォント・信頼済みルートを自動移行または削除しない。
- [x] Windows右クリックメニューは`Hiranoa.Open`のみを操作する。
- [x] 更新確認の固定URLを`cocoabreak/hiranoa`へ変更し、リダイレクト禁止を維持する。
- [x] 日英READMEに旧版の右クリック登録解除、新規インストール、手動ダウンロードを案内する。
- [x] アイコンをアプリ・配布形式・Aboutへ反映する。
- [x] 単一MD・フォルダー・ZIPと実アプリ表示を確認する。
- [x] 設計・セキュリティレビューに未解決P0/P1/P2がない。

## 対象外

旧版の自動移行、データ削除、機能追加、既存の公開済みタグ・配布物の書き換え。
