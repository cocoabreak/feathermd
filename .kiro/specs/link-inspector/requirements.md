# 要求定義: リンクインスペクターとローカルリンクグラフ

## 背景・目的

FeatherMDはWikiリンクの解決とバックリンク一覧に対応しているが、現在文書からの出力リンク、
通常のMarkdownリンク、リンク切れをまとめて確認する手段はない。

既存のDocumentSource、AllowedRoots、Wikiリンク解決規則を維持しつつ、現在文書を中心とした
リンク関係を一覧と1層のローカルグラフで確認できるようにする。

GitHub Issue: #1

## スコープ

- 既存バックリンク索引を拡張したSource単位の共通リンク索引
- Wikiリンクと同一DocumentSource内のローカルMarkdown文書リンク
- 現在文書の出力リンク、入力リンク、リンク切れの一覧
- 現在文書を中心とした1層のローカルリンクグラフ
- NativeSourceとZipSourceで共通の表示・遷移・更新動作

## 対象リンク

- `[[ページ名]]`、エイリアス・見出し付きWikiリンク
- Markdownのインラインリンクと参照形式リンク
- `.md`または`.markdown`文書への同一DocumentSource内リンク
- 見出しフラグメント付き文書リンク

## 対象外

- 外部URL、画像、Markdown以外のファイル
- クエリ文字列付きリンク
- 生HTML内のリンク
- 同一文書内の見出しリンク
- NativeSourceの信頼ルート外リンク、ZipSource外へのリンク
- フォルダー全体の常設グローバルグラフ
- 2層以上の探索、ノード位置の編集・永続化
- グラフ上での文書編集

## US-001: 現在文書のリンク関係を一覧で確認する

- [ ] 左サイドバーのリンクタブから「出力」「入力」「問題」を切り替えられる
- [ ] 出力には現在文書から解決済み文書へのリンクが表示される
- [ ] 入力には現在文書を参照する文書が表示される
- [ ] 問題には現在文書内のリンク切れが表示される
- [ ] リンク切れは出力一覧にも状態付きで残る
- [ ] 各項目にファイル名、Source内相対パス、Wiki／Markdownの種別、参照数を表示する
- [ ] 見出し付きリンクは見出し名を表示する
- [ ] 解決済み項目を選択すると既存の`openSourceMarkdown`経路で文書を開く
- [ ] 読込中、空、失敗、省略ありを区別して表示する

## US-002: WikiリンクとMarkdownリンクを同じ規則で索引する

- [ ] Wikiリンクは既存の候補索引と近接優先規則で解決する
- [ ] Markdownリンクは現在文書を基準にSource内相対パスへ正規化する
- [ ] 存在しない同一Source内文書リンクはリンク切れとして保持する
- [ ] 外部URL、画像、生HTML、コードスパン、コードブロック内の表現は索引しない
- [ ] 同一参照元から同じ対象への複数リンクは参照数へ集約する
- [ ] WikiリンクとMarkdownリンクが同じ文書を指す場合も対象文書単位で関連付ける
- [ ] 既存のWikiリンク遷移と索引結果が食い違わない
- [ ] Wikiリンクプラグイン無効時はMarkdownリンクだけを索引し、リンクタブ自体は利用できる
- [ ] Wikiリンクプラグイン有効時は既存バックリンクの結果と一致する

## US-003: 1層のローカルリンクグラフを確認する

- [ ] リンクサイドバーから専用モーダルを開ける
- [ ] 現在文書を中央、入力文書を左、出力文書を右へ配置する
- [ ] 入力と出力の両方に該当する文書は1ノードへ統合する
- [ ] リンク切れは破線の仮想ノードとして表示する
- [ ] エッジの方向とWiki／Markdownの種別を識別できる
- [ ] 解決済みノードを選択すると対象文書を開いてモーダルを閉じる
- [ ] `Escape`、閉じるボタン、フォーカストラップを利用できる
- [ ] キーボードだけで全ノードへ移動して選択できる
- [ ] 最大40ノードを表示し、全区分が応答上限内なら省略件数、それ以外は件数不明の省略状態を表示する

## US-004: 索引を安全かつ効率的に更新する

- [ ] リンクタブまたはグラフを初めて開くまで本文全走査を行わない
- [ ] Source ID、generation、隠しファイル設定、gitignore設定をキャッシュキーにする
- [ ] ファイル・ディレクトリ・Source更新後は次回表示時に再構築する
- [ ] 明示的な再読み込みで対象キャッシュを破棄できる
- [ ] 読込量、文書数、リンク数、解決検査数、同時構築数に上限を設ける
- [ ] 1文書、索引全体、1応答、文字列総量、一覧表示件数に個別の上限を設ける
- [ ] 上限到達や個別文書の読込失敗は部分結果と`truncated`で通知する
- [ ] NativeSourceとZipSourceの既存の信頼境界・圧縮データ制限を維持する

## 非機能要求

- 新しいフロントエンド・Rust依存関係を追加しない
- 新しいTauri capability、永続化ファイル、外部通信を追加しない
- リンクグラフは決定的なSVGレイアウトとし、物理シミュレーションを使用しない
- 一覧とグラフは同じ索引結果を使用する
- 一覧は各区分最大500件とし、完全な索引では省略Edge件数、索引打切り時は件数不明と表示する
- Wikiリンクプラグイン有効時の既存バックリンク結果・遷移・更新動作に回帰を起こさない

## 設計上の決定

- [x] 通常Markdownリンクも対象にする
- [x] 同一DocumentSource内のMarkdown文書リンクだけを対象にする
- [x] 既存バックリンク索引を共通リンク索引へ拡張する
- [x] グラフは専用モーダルへ表示する
- [x] v0.2.3は1層・最大40ノードとする
- [x] 同名Wikiリンクは既存規則で解決し、曖昧さをエラー扱いしない
- [x] リンク切れを仮想ノードとして表示する
