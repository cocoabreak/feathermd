# 要求定義: ローカルリンク先のホバープレビュー

## 背景・目的

WikiリンクやローカルMarkdownリンクの内容を確認するには、リンク先の文書を開く必要がある。
現在文書の閲覧位置を維持したまま、リンク先のタイトル、相対パス、見出し周辺を軽量な
ポップオーバーで確認できるようにする。

GitHub Issue: #2

## 前提

`link-inspector` specで導入する共通リンク解決契約と`DocumentRef`を再利用する。リンク索引全体の
構築はプレビュー表示の必須条件にせず、現在文書の解決済みリンク先だけを遅延読込する。

## スコープ

- 解決済みWikiリンクと同一DocumentSource内Markdown文書リンク
- ポインターホバーとキーボードフォーカスによる表示
- タイトル、相対パス、見出し、プレーンテキスト抜粋
- frontmatterの`title`、`aliases`、`tags`
- リンク切れ、読込失敗、サイズ・範囲制限の状態表示
- NativeSourceとZipSource
- 独立したリンクグラフウインドウの解決済み文書ノードとリンク切れノード

## 対象外

- 外部Webページ、画像、Markdown以外のファイル
- NativeSourceの絶対パスリンク（同一信頼ルート内を含む。明示クリック時の既存遷移は維持）
- NativeSourceの信頼ルート外リンク、ZipSource外リンク
- プレビュー本文のMarkdown／HTML再レンダリング
- プレビュー内リンクの連続遷移
- 固定表示、複数プレビュー、文書編集

## US-001: ポインターでリンク先を確認する

- [ ] 対象リンクへポインターを450ms置くとプレビューが表示される
- [ ] 450ms未満で離れた場合は文書を読み込まない
- [ ] リンクまたはポップオーバーから離れると150ms後に閉じる
- [ ] リンクからポップオーバーへ移動する間は表示を維持する
- [ ] 別リンクへ移動した場合は古い応答で表示を上書きしない
- [ ] Wikiリンクの解決前から滞在している場合も、解決完了後に新しいpointerイベントなしで表示を更新する
- [ ] クリック時は既存どおりリンク先を開く

## US-002: キーボードでリンク先を確認する

- [ ] 対象リンクへフォーカスすると同じプレビューを表示する
- [ ] フォーカスがリンクから外れると150ms後に閉じる
- [ ] `Escape`で閉じ、元のリンクのフォーカスを維持する
- [ ] ポップオーバーの内容と状態が支援技術へ通知される
- [ ] プレビューがリンクのクリック・Enter操作を妨げない

## US-003: 軽量な概要を表示する

- [ ] frontmatterの`title`、なければファイル名をタイトルにする
- [ ] Source内相対パスを表示する
- [ ] 見出し付きリンクは対象見出しと直後の本文を優先する
- [ ] 見出しなしリンクは文書冒頭の本文を表示する
- [ ] 抜粋はMarkdown記号を除いたプレーンテキスト最大320文字とする
- [ ] `aliases`と`tags`があれば文字列または文字列配列だけを表示する
- [ ] `title`と各メタデータ要素は最大256文字、`aliases`と`tags`は各32件まで表示する
- [ ] 表示するfrontmatterメタデータはUTF-8で合計8KiB以下とし、超過時は省略を表示する
- [ ] スクリプト、HTML、SVG、画像、外部コンテンツを描画しない

## US-004: 失敗と負荷を安全に扱う

- [ ] 解決時点でリンク切れと判明しているWikiリンクは文書読込を行わず状態を表示する
- [ ] Wikiリンクの`pending`、`resolved`、`missing`を信頼済みレジストリで区別する
- [ ] Markdownリンクの存在しない文書は制限付き読込の失敗から安全なリンク切れ表示にする
- [ ] 先頭256KiBまでの読込でタイトル・見出し・抜粋を生成する
- [ ] 対象見出しが読込範囲外の場合はその状態を表示する
- [ ] 読込失敗、UTF-8不正、Source更新、エントリ削除を区別せず安全な失敗表示にする
- [ ] 存在しない文書は構造化された`missing`結果で判定し、文字列エラーを解析しない
- [ ] 同じSource generationとDocumentRefの結果を最大32件だけメモリキャッシュする
- [ ] キャッシュへ保持する派生メタデータにも件数・文字列総量上限を適用する
- [ ] Source generation変更と既知のwatcherイベント後はキャッシュを無効化する
- [ ] 並行要求はlatest-onlyとし、古い応答を破棄する
- [ ] DOM属性からSource IDやDocumentRefを受け取らず、現在Sourceとの同一性をRust側でも検証する

## US-005: リンクグラフから文書を確認する

- [ ] 解決済み文書ノードへポインターを450ms置くと同じ文書プレビューを表示する
- [ ] 現在文書ノードもプレビューできる
- [ ] リンク切れノードは文書を読み込まず、リンク切れ状態と対象パスを表示する
- [ ] グラフのキーボード選択でも選択ノードのプレビューを表示する
- [ ] ノードのクリック、Enter、Spaceによる既存の文書遷移を妨げない
- [ ] グラフウインドウ内にPopoverとStoreを1つだけ持ち、メインウインドウと状態を共有しない
- [ ] コンテキスト更新、ノード削除、ウインドウ終了時にタイマー・要求・表示を破棄する

## 非機能要求

- 新しい依存関係、Tauri capability、永続化、外部通信を追加しない
- プレビューを使用しない場合の本文レンダリングとリンク遷移コストを増やさない
- 位置計算はビューポート内に収め、ウィンドウサイズ変更・スクロール時に更新する
- ポップオーバーは本文より前面に表示するが、モーダルにはしない
- グラフノードの位置はCytoscapeの描画境界から算出し、DocumentRefをDOM属性へ保存しない

## 設計上の決定

- [x] WikiリンクとMarkdownリンクの両方を対象にする
- [x] 外部Webページは対象外とする
- [x] 450msで表示、150msで非表示とする
- [x] 抜粋はプレーンテキスト最大320文字とする
- [x] frontmatterは`title`、`aliases`、`tags`だけを表示する
- [x] 専用の256KiB制限読込コマンドを使用する
- [x] プレビュー内リンク操作と固定表示は対象外とする
- [x] リンクグラフの解決済み文書ノードとリンク切れノードも対象にする
